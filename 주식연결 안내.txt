부산기 주식 기능 — 로컬 사용

1. '주식서버 시작.cmd'를 더블클릭하고, 현재가 연결 확인 메시지가 나올 때까지 기다립니다.
2. 기존 index.html을 열어 게임시작 → 주식으로 이동합니다.
   기존 게임의 진행 상황은 기존 파일 주소를 그대로 열어야 유지됩니다.
   또는 http://127.0.0.1:4173/#stocks 에서 게임을 열 수 있습니다.
   파일 주소와 HTTP 주소는 서로 다른 브라우저 저장 공간을 사용합니다.
3. 현재가 조회 → 수량·매수/매도 선택 → 게임머니로 주문하기.
4. 서버 창을 닫으면 시세 연결이 종료됩니다.

실제 증권계좌 주문 API는 구현되어 있지 않습니다.
실제 현재가를 조회하고, 게임머니와 가상 주식 잔고만 변경합니다.
현재가는 조회·주문 시 갱신됩니다. 실시간 WebSocket 스트리밍은 아닙니다.
장 마감·휴장 시 마지막 가격으로 게임 거래합니다.
매수·매도 수수료는 게임 규칙상 각각 0.1%입니다.

App Key, App Secret, 인증 토큰은 웹폴더 밖 ../.busangi-private 에
현재 Windows 사용자용 DPAPI로 암호화해 보관합니다.
복호화된 키·토큰은 로컬 서버 메모리에만 있으며 브라우저로 보내지 않습니다.
서버는 127.0.0.1:4173에서만 실행하고 비밀 파일을 제공하지 않습니다.
일반 정적 미리보기 preview.cjs 대신 market-server.cjs를 사용합니다.
키를 다시 발급할 경우 기존 암호화 인증 토큰도 갱신해야 합니다.

현재 게임 잔액과 거래 기록은 로컬 시제품의 브라우저 저장 방식입니다.
여러 사용자에게 공개하기 전에는 계정·잔액·거래를 서버에 저장하고,
시세 데이터 제공자의 공개 서비스 이용·재배포 조건을 확인해야 합니다.
