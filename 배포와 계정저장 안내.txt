현재 기능
- 닉네임(한글/영문/숫자/기호)과 비밀번호로 가입 및 로그인
- 비밀번호 scrypt 해시, HttpOnly 세션 쿠키, 계정별 SQLite 진행 저장
- 저장된 재화·능력치·의상·자산을 다른 브라우저에서 복원
- 부산역 광장: 같은 서버에 실제로 접속한 사용자끼리 위치·의상·채팅 공유
- 로컬 주소: http://127.0.0.1:4173/
- 기존 file:// 게임의 회원가입/로그인 버튼을 누르면 현재 진행을 서버 주소로 가져갑니다.
- 새 계정 가입 시 '현재 진행 상황 가져오기'를 체크하면 현재 게스트 진행을 계정에 저장합니다.
- 기존 계정에 로그인하면 그 계정의 서버 기록을 불러옵니다.
- 두 창에서 같은 계정을 동시에 플레이하면 저장 충돌을 표시해 덮어쓰기를 막습니다.
- 같은 계정은 광장에 한 명으로 표시합니다. 다른 탭에서 입장하면 이전 접속이 종료됩니다.

GitHub 배포 준비
GitHub에 소스를 올리는 것과 게임 서버를 실행하는 것은 별개입니다.
GitHub Pages는 정적 파일만 제공하므로 회원 저장/로그인/실시간 광장 서버는 실행할 수 없습니다.
전체 저장소를 Node.js 24 이상을 지원하는 서버 호스팅에 연결해 npm start로 실행하면
화면과 API를 같은 HTTPS 주소에서 제공할 수 있습니다.

서버 환경 변수
PORT: 호스팅 서비스가 지정하는 포트
BUSANGI_BIND: 외부 배포 시 0.0.0.0 (기본값은 안전한 로컬 127.0.0.1)
BUSANGI_PUBLIC_ORIGIN: 실제 게임 HTTPS 주소, 예: https://게임주소
BUSANGI_DATA_DIR: 영구 디스크 경로 (accounts.sqlite 저장 위치)
KIS_APP_KEY / KIS_APP_SECRET: 호스팅의 비밀 환경 변수로 등록, Git에 넣지 않음
Windows 로컬에서는 기존 DPAPI 암호화 키를 그대로 사용합니다.
클라우드 환경 변수로 인증 시 토큰은 서버 메모리에만 유지합니다.

다른 PC·휴대폰도 같은 HTTPS 게임 주소에 접속해야 같은 계정과 광장을 이용합니다.
영구 디스크 없는 임시 호스팅에서는 재배포 시 회원 저장이 사라질 수 있으므로
BUSANGI_DATA_DIR를 반드시 영구 저장소로 지정해야 합니다.
기존 .busangi-private 폴더에는 키와 회원 DB가 있으므로 공개 저장소에 올리지 않습니다.
계정 복구 이메일, 비밀번호 변경, 서버 검증을 통한 부정 재화 방지는 아직 시제품 범위입니다.
공개 운영 전 시세 재배포 조건과 계정 운영 기능을 검토해야 합니다.
