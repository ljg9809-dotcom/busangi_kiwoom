# 부산기 키우기

부산을 여행하며 일하고 공부하고 캐릭터를 꾸미는 웹게임 시제품입니다.

## 로컬 실행

Node.js 24 이상에서 `npm start` 또는 Windows의 `주식서버 시작.cmd`를 실행하고
<http://127.0.0.1:4173/> 에 접속합니다. 별도 npm 의존성 설치는 필요하지 않습니다.

- 카페 주문 제작: 1~4키/터치로 재료 선택, 60초 근무, 자동 서빙·콤보·완료 보너스
- 굿즈 4종과 기존 의상 구매·착용, 행동별 배너 반영
- 부산역 광장: 방향키/터치 이동, 접속자 의상·프로필, 실시간 채팅
- 1분 공부마다 지능 +1, 최대 100
- 공식 코스피·코스닥 목록으로 종목명/코드 검색, 실제 현재가로 게임머니 거래
- 닉네임·비밀번호 가입, 계정별 서버 저장·로그인 복원

기존 파일 게임에서 회원가입 버튼을 누르면 진행 상황을 로컬 서버로 가져갑니다.
가입 시 현재 진행 가져오기를 선택하면 해당 계정에 저장합니다.

## 키와 저장 데이터

실제 증권계좌 주문 API는 구현하지 않았습니다. 주가 조회만 사용합니다.
로컬 API 키·토큰은 웹폴더 밖 `.busangi-private`에 Windows DPAPI로 암호화해 보관합니다.
비밀번호는 scrypt 해시로, 진행 기록은 비공개 SQLite DB로 저장합니다.
키·토큰·회원 DB·환경 변수 파일은 Git에 포함하지 않습니다.

테스트: `npm test`.
업로드 전 로컬에서 `node check-secrets.cjs`로 Git에 포함된 파일을 검사합니다.
이 검사기는 실제 키 값을 출력하지 않습니다.

## 클라우드 배포

Vercel 화면과 Supabase 데이터베이스·Edge Function을 연결합니다. 다른 PC·휴대폰에서도 같은 계정으로 이어 할 수 있습니다. 설정과 보안 구조는 [VERCEL-DEPLOY.md](VERCEL-DEPLOY.md)를 참고하세요.

## 이미지 제작 기록

내장 이미지 생성 도구로 기존 부산기 원화·굿즈를 참고해 의상과 행동 이미지를 제작했습니다.
의상 PNG와 파일 실행용 데이터 패키지는 `assets/wardrobe/`에 있습니다.
최종 프롬프트와 보정 기록도 같은 폴더의 JSON 파일로 보관합니다.

카페 유니폼·배경 원화: `assets/cafe-barista.png`. 내장 imagegen으로 제작했으며 프롬프트는 `assets/cafe-barista-prompt.txt`에 보관합니다.

## RANKIING

회원별 마지막 서버 저장 기록으로 전체 성장 순위를 집계합니다. 현재 직장 점수는 중소기업 1,000 / 중견기업 2,000 / 공무원 3,000 / 공기업 4,000 / 대기업 5,000점이며 미취업은 0점입니다. 이직 이력은 합산하지 않습니다.
자산 점수는 (현금 + 자산 카탈로그 가격 × 보유 지분 + 보유 주식의 조회 시세 × 수량)을 10,000원으로 나눈 정수입니다. 의상과 미수령 수익은 제외하며 주식은 서버 조회 시세 기준 평가액입니다. 1분 동안 시세를 재사용하며, 조회 실패 시 기존 시세 사용 여부를 화면에 표시합니다. 시세가 전혀 없는 보유 종목은 합계를 임의 산정하지 않고 조회 오류를 안내합니다. 동일 점수는 공동 순위(1, 1, 3), 목록은 20명씩 표시합니다.
GET /api/ranking?page=1은 공개 순위 정보만 반환합니다. 내 순위는 쿠키 세션으로 판별하며 비밀번호·세션 토큰·원본 저장 데이터는 반환하지 않습니다. 서버가 점수를 재계산하지만 현재 진행 상태 자체는 클라이언트 저장을 받는 시제품 구조이므로, 경쟁 보상이 있는 정식 서비스 전에는 게임 행동과 재화를 서버에서 검증해야 합니다.

## 페이지별 배너와 통합 옷장

나의 부산기는 `assets/busangi-standing.png`의 기본 서 있는 자세와 흰 배경을 사용합니다. 옷장은 나의 부산기 안에 있으며, 서 있는 의상 9종은 `assets/wardrobe/atlases/stand.png`에 있습니다. 기존 #closet 링크는 #home으로 이동합니다. 독서실 진입은 공부 자세, 부산 여행 진입은 항상 부산역 광장 배경과 경치 감상 자세를 즉시 표시하며 실제 공부 타이머나 저장된 활동을 변경하지 않습니다. 여행 화면에서 식사·음료·여가를 선택하면 해당 행동으로 바뀝니다. 서 있는 의상 원화는 내장 imagegen으로 제작했으며 프롬프트는 `assets/wardrobe/standing-prompt.txt`에 보관합니다.

Vercel 배포 연결과 현재 서버 구조의 제약은 [VERCEL-DEPLOY.md](VERCEL-DEPLOY.md)를 참고하세요. 가입 창은 로그인/회원가입 탭과 가입 완료 단계를 제공하며 비밀번호 원문을 저장하지 않습니다.
